Important Formulae: Science Class - 9
Chapter - 8

Important Formulae

The following are the most important formulae and relations from Chapter 8: Journey Inside the Atom. Learn these thoroughly for examinations and numerical problems.

Formula Meaning
Atomic Number (Z) = Number of Protons (p) The atomic number of an element is equal to the number of protons present in its nucleus.
For a Neutral Atom:
Number of Electrons (e) = Number of Protons (p)		 A neutral atom has equal numbers of protons and electrons.
Mass Number (A) = Number of Protons + Number of Neutrons The mass number is the total number of nucleons present in the nucleus.
A = p + n Short form of the Mass Number formula.
Number of Neutrons (n) = Mass Number − Atomic Number Used to calculate the number of neutrons present in an atom.
n = A − Z Short form of the neutron formula.
Maximum Electrons in nth Shell = 2n² Bohr–Bury rule used to calculate the maximum number of electrons in any shell.

Bohr–Bury Rule

Shell Value of n Maximum Electrons (2n²)
K 1 2
L 2 8
M 3 18
N 4 32

Remember

  • ✔ Atomic Number is represented by Z.
  • ✔ Mass Number is represented by A.
  • ✔ Number of nucleons = Protons + Neutrons.
  • ✔ A neutral atom always has equal numbers of protons and electrons.
  • ✔ The outermost shell can have a maximum of 8 electrons (except the K-shell, which can have only 2 electrons).
