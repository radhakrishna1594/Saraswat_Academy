Chapter 6: Exploring some more Progressions

Relations and functions are fundamental concepts in mathematics that describe the relationship between two sets of elements.

A relation is a set of ordered pairs, where each pair consists of an element from the first set and an element from the second set. A function is a special type of relation where each element in the first set (domain) is associated with exactly one element in the second set (range).

Functions can be represented in various ways, including:

  • Set notation: Using ordered pairs to represent the function.
  • Graphical representation: Plotting points on a coordinate plane to visualize the function.
  • Algebraic expression: Using equations to define the relationship between variables.

Understanding relations and functions is crucial for further studies in mathematics, as they form the basis for more advanced topics such as calculus and linear algebra.

EXERCISE 6.1

Question 1

Find the sum of the series 0.15 + 0.015 + 0.0015 + … to 15 terms.

This is a GP with first term a = 0.15 and common ratio r = 0.1. Using Sn = a(1 − rn)/(1 − r):

S15 = 0.15(1 − 0.115)/0.9 = (1/6)(1 − 10−15).

Question 2

Find the sum to n terms of 0.9 + 0.99 + 0.999 + …

Write the kth term as 1 − 10−k. Therefore

Sn = n − (10−1 + 10−2 + … + 10−n).

The bracket is a GP, so its sum is (1/9)(1 − 10−n). Hence Sn = n − (1/9)(1 − 10−n).

Question 3

Find the sum to n terms of 5 + 55 + 555 + …

The kth term is 5(111…1) = 5(10k − 1)/9.

Therefore Sn = (5/9)[(10 + 102 + … + 10n) − n].

Since 10 + 102 + … + 10n = 10(10n − 1)/9,

Sn = 5[10(10n − 1) − 9n]/81.

Question 4

The sum of the first n terms of 3, 6, 12, … is 381. Find n.

This is a GP with a = 3 and r = 2. Thus Sn = 3(2n − 1)/(2 − 1) = 3(2n − 1).

So 3(2n − 1) = 381 ⇒ 2n = 128 = 27.

n = 7.

Question 5

Find the sum to n terms of x(x + y) + x2(x2 + y2) + x3(x3 + y3) + …

The kth term is x2k + xkyk. Hence the sum is the sum of two GPs:

Sn = x2(x2n − 1)/(x2 − 1) + xy[(xy)n − 1]/(xy − 1), for x2 ≠ 1 and xy ≠ 1.

Question 7

The sum of an infinite GP is 6 and the sum of the squares of its terms is 12. Find the common ratio.

Let the first term be a and common ratio r. Then a/(1 − r) = 6 and a2/(1 − r2) = 12.

Using a = 6(1 − r):

36(1 − r)2/[(1 − r)(1 + r)] = 12.

Thus 3(1 − r) = 1 + r, giving r = 1/2.

Question 8

If the sum to infinity of 1 + r + r2 + r3 + … is S, where |r| < 1, write r in terms of S.

S = 1/(1 − r).

Therefore 1 − r = 1/S and r = 1 − 1/S = (S − 1)/S.

Question 9

Find the value of 42 · 44 · 48 · 416 · … to infinity.

Interpreting the product literally, the exponents are 2, 4, 8, 16, …, so the product is

42+4+8+16+….

The exponent diverges to infinity; hence this product does not converge to a finite real value. It diverges.

Question 10

The midpoints of the sides of an equilateral triangle are joined repeatedly. If each side of the original triangle is 16 cm, find the sum of the perimeters of all triangles formed.

Each new triangle has half the side length of the previous one. The perimeters therefore form a GP: 48, 24, 12, … with r = 1/2.

Sum to infinity = 48/(1 − 1/2) = 96 cm.

Question 11

Let f(x) = 2x + 1. Find the number of values of x for which f(x), f(2x), f(4x) are in GP.

We have f(x)=2x+1, f(2x)=4x+1, f(4x)=8x+1. For three numbers in GP:

(4x + 1)2 = (2x + 1)(8x + 1).

Expanding gives 16x2 + 8x + 1 = 16x2 + 10x + 1, so 2x = 0 and x = 0.

Hence there is 1 value of x.

Question 12

If t1, t2, … are terms of a GP with common ratio |r| < 1, evaluate (t1 − t3 + t5 − …)/(t2 − t4 + t6 − …).

Let the first term be a. The numerator is a − ar2 + ar4 − … = a/(1 + r2). The denominator is ar − ar3 + ar5 − … = ar/(1 + r2).

Therefore the required value is 1/r, provided r ≠ 0.

Question 13

A ball rebounds to 3/5 of its previous height. It falls from a height of 90 m. Find the total distance travelled before coming to rest.

The first fall is 90 m. After each bounce, the upward heights form a GP: 90(3/5), 90(3/5)2, … .

Total distance = 90 + 2[90(3/5) + 90(3/5)2 + …].

Sum of the infinite GP inside brackets = 54/(1 − 3/5) = 135.

Total distance = 90 + 2(135) = 360 m.

EXERCISE 6.2

Question 1

Find the nth term and the sum of the first n terms of 1 + 9 + 24 + 46 + 75 + …

First differences are 8, 15, 22, 29, …, an AP with first term 8 and common difference 7.

Therefore tn = 1 + [8 + 15 + … up to n − 1 terms] = 1 + (n − 1)(n + 14)/2.

Hence tn = (n2 + 13n − 12)/2.

For the sum, use the method-of-differences formula Sn = bC(n,1) + aC(n,2) + dC(n,3), with b=1, a=8, d=7:

Sn = n + 8C(n,2) + 7C(n,3).

Question 2

Find the 10th term and the sum of the first 10 terms of 4 + 5 + 9 + 16 + 26 + …

First differences: 1, 4, 7, 10, … . Thus b=4, a=1, d=3.

t10 = 4 + 1·C(9,1) + 3·C(9,2) = 4 + 9 + 108 = 121.

S10 = 4·10 + 1·C(10,2) + 3·C(10,3) = 40 + 45 + 360 = 445.

Question 3

Find the nth term and the sum of the first 12 terms of 3 + 6 + 11 + 18 + 27 + …

First differences are 3, 5, 7, 9, …, so b=3, a=3, d=2.

tn = 3 + 3(n − 1) + 2(n − 1)(n − 2)/2 = n2 + 2.

Thus t12 = 146. Also S12 = 3·12 + 3C(12,2) + 2C(12,3) = 36 + 198 + 440 = 674.

Question 4

Find the 8th term and the sum of the first 8 terms of 4 + 13 + 28 + 49 + 76 + …

First differences are 9, 15, 21, 27, …, so b=4, a=9, d=6.

t8 = 4 + 9·C(7,1) + 6·C(7,2) = 4 + 63 + 126 = 193.

S8 = 4·8 + 9C(8,2) + 6C(8,3) = 32 + 252 + 336 = 620.
