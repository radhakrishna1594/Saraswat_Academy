5. Categorise the following as syntax error, logical error or runtime error.

(a) 25 / 0

Runtime Error

The statement is syntactically correct, but division by zero cannot be performed during execution. Python therefore generates a runtime error.

(b)

num1 = 25
num2 = 0
num1 / num2

Runtime Error

The denominator is zero, so the program generates a division-by-zero error during execution.

6. Write a Python program to calculate the amount payable on simple interest.

Given: 

SI = (P × R × T) / 100
Amount = Principal + SI

Program:

R = float(input("Enter the rate of interest: "))
T = float(input("Enter the time in years: "))

SI = (P * R * T) / 100
Amount = P + SI

print("Simple Interest =", SI)
print("Amount Payable =", Amount)

10. What is the difference between else and elif construct of if statement?

else elif
else is executed when the preceding if condition is false. elif is used to check another condition when the preceding condition is false.
It does not have a condition of its own. It always contains a condition.
It is normally used as the final alternative. Multiple elif blocks can be used to check multiple conditions.

Example:

marks = int(input("Enter marks: "))

if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
else:
    print("Grade D")
