Computer System: Complete Notes for Class 11 & 12

A computer system is more than a screen and a keyboard. It is a combination of hardware, software, data and people working together to accept input, process it, store information and produce useful output.

This chapter explains the computer system from the basics, with labelled diagrams, comparisons, everyday examples and exam-oriented questions for senior-secondary students.

CBSE syllabus note: Computer organisation, hardware and software, input/output devices, CPU, memory and units of memory are explicitly included in Class XI Computer Science (083). Class XI Informatics Practices (065) also covers the evolution of computing devices, computer components and interconnections, memory, software types, and concerns around deletion and recovery of data. The exact scope differs by subject and academic session, so use your current syllabus alongside these notes. 1. Introduction to a Computer System

A computer is an electronic, programmable device that accepts data as input, processes it according to instructions, stores data or results, and produces information as output. A computer system includes the physical equipment, programs, data and people or procedures needed to perform a task.

Data and information

  • Data: raw facts that have not yet been meaningfully processed, such as the marks 72, 85 and 91.
  • Information: processed data that is meaningful, such as the average mark of those students.
  • Instruction: a command telling the computer what operation to perform.
  • Program: a set of instructions written to solve a problem or perform a task.

Characteristics of computers

CharacteristicExplanationExample
SpeedPerforms millions or billions of operations per second, depending on the system.Calculating results for thousands of students quickly.
AccuracyCan produce highly accurate results when data and instructions are correct.Calculating a fee total using the correct formula.
DiligenceCan repeat tasks without human-style tiredness.Processing many records in the same way.
StorageStores large quantities of data for later use.Saving documents and photographs on a drive.
VersatilityPerforms many different types of tasks.Writing, designing, programming and communication.
AutomationOnce set up, a task can run with limited ongoing human intervention.Generating a report from a prepared spreadsheet.
Important limitation: a computer does not automatically know whether the instructions or input are sensible. Incorrect input or logic can produce incorrect output—often summarised as “Garbage In, Garbage Out” (GIGO).

2. Components of a Computer System

The main functional units are the input unit, central processing unit (CPU), primary memory/storage and output unit. The CPU contains the Arithmetic Logic Unit (ALU), Control Unit (CU) and registers. Main memory supplies instructions and data to the processor.

2.1 Hardware and software

  • Hardware is the physical part that can be seen or touched: CPU, RAM, keyboard, monitor, SSD and motherboard.
  • Software is the set of programs and related instructions that tell hardware what to do: operating systems, browsers, editors and games.
  • Firmware is software stored in non-volatile memory that helps control a device, such as firmware used during system startup.

2.2 Input devices

DevicePurpose / example

2.3 Output devices

A touchscreen is both an input and an output device. A printer produces hard copy; a monitor displays soft copy.

2.4 Inside the CPU

  • ALU (Arithmetic Logic Unit): performs arithmetic operations and logical comparisons.
  • CU (Control Unit): directs and coordinates the execution of instructions and movement of data.
  • Registers: tiny, high-speed storage locations inside the processor for current instructions, addresses and data.

The CPU fetches an instruction, decodes it and executes it. This is often described as the fetch–decode–execute cycle. Cache and registers help keep frequently needed information close to the processor.

3. Timeline: Evolution of Computing Devices

Computer evolution did not happen in one straight line. Early calculating tools, mechanical machines, electronic computers, integrated circuits and modern mobile/cloud systems each added new capabilities. The timeline below highlights widely taught milestones; dates are approximate for broad eras.

3.1 Four generations of electronic computers

GenerationMain technologyGeneral characteristics
FirstVacuum tubesVery large, hot, expensive and power-hungry; machine-level programming was common.
SecondTransistorsSmaller, more reliable and more efficient than vacuum-tube machines.
ThirdIntegrated circuits (ICs)Many components integrated into chips; improved reliability and processing capability.
FourthMicroprocessors / VLSIPowerful personal computers and embedded systems became practical at scale.
Later / emerging systemsParallel processing, cloud, AI and other technologiesOften discussed as modern developments; there is no single universally agreed “fifth-generation” definition.
Exam tip: If a question asks for the four traditional generations, write vacuum tubes, transistors, integrated circuits and microprocessors in that order. Do not confuse the “generation” classification with the historical timeline of individual devices.

4. Computer Memory

Computer memory stores instructions, input data, intermediate results and final output. Memory is commonly classified as primary memory, cache and secondary storage. The terms “memory” and “storage” are sometimes used casually as if they were identical, but they serve different roles.

4.1 Primary memory

Primary memory is directly accessible to the processor or used as its immediate working memory. RAM and ROM are the standard examples taught at this level.

RAMROM
Random Access Memory; holds programs and data currently in use.Read-Only Memory; traditionally stores instructions needed for startup or device operation.
Volatile: its contents are lost when power is removed.Non-volatile: retains stored contents without power.
Usually read from and written to during normal operation.Often read during normal operation; the method of updating depends on the ROM technology.
Examples include DRAM used as main memory and SRAM used in cache.Examples include firmware stored in flash/ROM-type memory.

4.2 Cache memory

Cache is small, very fast memory that stores copies of data or instructions likely to be needed by the CPU soon. It reduces the average time needed to access data from slower main memory. Modern processors may have L1, L2 and L3 cache levels; the exact design differs by processor.

4.3 Registers

Registers are storage locations inside the CPU. They are extremely fast but very limited in capacity. They may hold operands, addresses, instructions or intermediate results during execution.

4.4 Secondary memory / storage

Device / mediumTypeUseful point
Hard disk drive (HDD)MagneticStores data on rotating magnetic platters; often offers large capacity.
Solid-state drive (SSD)Flash storageHas no moving disk parts; commonly faster for everyday access than an HDD.
USB flash drive / memory cardFlash storagePortable and rewritable.
CD / DVD / Blu-rayOpticalUses laser technology to read/write supported discs.
Magnetic tapeMagneticUseful for backup and archival storage; typically sequential access.

Secondary storage is non-volatile and generally offers much greater capacity than RAM. It retains files when the computer is switched off, but accessing it is normally slower than accessing registers, cache or RAM.

5. Units of Memory

The smallest unit is a bit, which can represent 0 or 1. A group of 8 bits is one byte. A character is often stored in one or more bytes depending on the encoding.

UnitCommon binary value used in school problemsApproximate decimal value
1 bit0 or 1—
1 byte (B)8 bits8 bits
1 KB1,024 bytesAbout 1 thousand bytes
1 MB1,024 KBAbout 1 million bytes
1 GB1,024 MBAbout 1 billion bytes
1 TB1,024 GBAbout 1 trillion bytes

Accuracy note: In many school exercises, KB, MB, GB and TB are calculated using 1,024. In formal storage terminology, the binary units are KiB, MiB, GiB and TiB (each based on 1,024), while KB, MB, GB and TB can denote decimal multiples of 1,000. Follow the convention specified in your question.

Solved examples

Example 1: Convert 4 KB into bytes

Using the school convention, 1 KB = 1,024 bytes.

4 × 1,024 = 4,096 bytes.

Example 2: Convert 3 MB into KB

3 × 1,024 = 3,072 KB.

Example 3: How many bits are there in 5 bytes?

5 × 8 = 40 bits.

6. Types of Software

Software is a collection of programs and related instructions that enable a computer to perform tasks. It is commonly divided into system software and application software. Programming tools are used to create, translate and test programs.

6.1 System software

System software manages the computer and provides a platform for application programs.

  • Operating system: manages memory, files, processes, devices and user interaction. Examples: Windows, GNU/Linux, macOS, Android and iOS.
  • Device driver: allows the operating system to communicate with a hardware device, such as a printer or graphics adapter.
  • Utility software: supports maintenance, protection or management. Examples include backup utilities, file-compression tools and security scanners.
  • Language translator: converts source code or assembly instructions into a form the computer can execute.

6.2 Application software

Application software helps a user perform a task. It can be classified by purpose.

TypeMeaningExamples
General-purpose / genericDesigned for many users and a wide range of common tasks.Word processors, spreadsheets, presentation software, web browsers.
Specific-purpose / customisedDesigned for a particular task, organisation or workflow.School fee-management system, railway reservation system, hospital appointment software, payroll system.

“Generic” and “general-purpose” are often used similarly in school explanations. Specific-purpose software can be developed for one organisation or a narrow activity.

6.3 Programming tools and translators

Tool / translatorWhat it doesExam-ready distinction
AssemblerTranslates assembly language into machine code.Assembly language uses mnemonic instructions.
CompilerTranslates a program or source unit before execution, often producing object code or an executable.Reports errors during translation; exact behaviour depends on the language and toolchain.
InterpreterExecutes source code through an interpreter/runtime.Often described as processing instructions step by step; modern implementations may use bytecode or JIT compilation.
DebuggerHelps inspect execution, set breakpoints and find faults.Used for debugging, not simply for translation.
Do not overgeneralise: school questions often contrast compiler and interpreter in simplified terms. In real implementations, language runtimes may combine compilation, interpretation and just-in-time techniques.

7. Open-Source Software and Other Software Models

Open-source software (OSS) is software distributed under a licence that grants users rights to access and use the source code and, subject to licence conditions, study, modify and redistribute it. “Open source” is about the rights granted by the licence—not simply whether a program is free of cost.

7.1 Examples of open-source software

Software / projectTypical useImportant note
GNU/Linux distributionsOperating systems for desktops, servers and embedded devices.Many distributions combine software under different licences.
LibreOfficeDocuments, spreadsheets and presentations.Open-source office productivity suite.
Mozilla FirefoxWeb browsing.Open-source browser project.

GIMPImage editing.Open-source raster graphics editor.
VLC media playerPlaying audio and video.Open-source media player.
Blender3D modelling, animation and rendering.Open-source 3D creation suite.

7.2 Advantages and limitations

Potential advantagesPossible limitations / responsibilities
Source code can be inspected under the licence.Reading and maintaining code may require technical skills.
Users may modify the software and share changes when the licence permits.Redistribution and derivative works must comply with the licence.
Community contributions can improve features and fix defects.Support and documentation quality vary by project.
Often reduces dependence on a single vendor.Deployment, training, migration and maintenance may still cost money.

7.3 Open source vs freeware vs shareware vs proprietary

TermMeaningSource-code / usage rights
Open sourceSoftware whose licence provides source-code access and defined rights to use, modify and redistribute.Rights depend on the particular open-source licence.
FreewareSoftware available to use without a purchase price.Source code and modification rights are not automatically provided.
Shareware / trialwareSoftware offered for evaluation or limited use, often with payment needed for continued/full use.Usually governed by the vendor's terms; not automatically open source.
Proprietary / closed-sourceSoftware controlled by an owner under restrictive licence terms.Users generally cannot freely modify or redistribute it.
Commercial softwareSoftware supplied as part of a business model, often for payment or support.May be proprietary or open source; “commercial” does not automatically mean closed-source.
Common exam misconception: “Free of cost” and “open source” do not mean the same thing. A freeware program can be closed-source, and open-source software can be sold or supported commercially.

7.4 Free and open-source software (FOSS)

FOSS refers to free/libre and open-source software. Here, “free” often emphasises freedom to use, study, modify and share—not necessarily a zero price. Licence examples include the GNU General Public License (GPL), MIT License and Apache License. Their conditions differ, so one licence should not be treated as identical to another.

7.5 Public domain and Creative Commons are not identical to open-source software licences

Public-domain works have no enforceable copyright restrictions in the relevant jurisdiction or have been dedicated to the public domain. Creative Commons licences are mainly used for creative works such as text, images and media; they are not generally recommended as a substitute for a software-specific open-source licence. Always check the licence of the actual work.

8. Operating System (OS)

An operating system is system software that manages hardware resources and provides services for applications and users. It acts as an interface between applications/users and the hardware.

8.1 Main functions of an operating system

  • Process management: creates, schedules and coordinates running processes.
  • Memory management: allocates and tracks memory used by programs.
  • File management: organises files and folders and controls access.
  • Device management: coordinates input/output devices through drivers and system services.
  • User interface: offers a graphical user interface (GUI), command-line interface (CLI), or both.
  • Security and access control: manages accounts, permissions and other protection mechanisms.
  • Error handling and resource allocation: detects certain faults and distributes system resources.

8.2 GUI and CLI

GUI — Graphical User InterfaceCLI — Command-Line Interface
Uses visual elements such as windows, icons, menus and pointers.Uses text commands entered at a prompt or terminal.
Often easier for beginners to discover visually.Can be efficient for repetitive, scripted or remote administration tasks.
Example: opening a folder through a file manager.Example: listing files with a terminal command.

8.3 Examples of operating systems

Microsoft Windows, GNU/Linux distributions, macOS, Android and iOS are examples. An operating system is not the same as a web browser, word processor or device driver, although drivers work closely with the OS.

9. Data Deletion, Recovery and Security

Deleting a file does not always mean every underlying data bit has immediately disappeared. Depending on the file system and device, deletion may first remove the directory reference or mark storage space as available for reuse. Recovery may be possible until data is overwritten, but it is never guaranteed.

  • Recycle Bin / Trash: often provides a way to restore recently deleted files, unless permanently deleted or bypassed.
  • Backups: copies stored separately help restore data after accidental deletion, device failure or malware.
  • Recovery tools: may recover some files if the relevant data has not been overwritten and the device remains accessible.
  • Secure deletion: methods depend on the storage medium. On SSDs, wear levelling and internal remapping can make ordinary overwrite-based approaches unreliable; manufacturer-supported secure erase or encryption-based sanitisation may be more appropriate.
  • Privacy and security: use strong authentication, access controls, encryption and trusted backups for sensitive data.
Practical safety: If you accidentally delete an important file, stop saving new data to the same drive and check the Trash/Recycle Bin and backups first. Continued use can overwrite recoverable data. Do not store only one copy of important school or personal work.

10. Exam-Oriented Questions with Answers

These are original revision questions based on the concepts listed in CBSE syllabi. They are practice questions, not claimed to be verbatim copies of specific previous-year board questions.

1 mark

Q1. Which component performs arithmetic calculations and logical comparisons?

(a) CU   (b) ALU   (c) RAM   (d) SSD

Show answer

Answer: (b) ALU. The Arithmetic Logic Unit performs arithmetic and logical operations.

1 mark

Q2. Which memory is volatile?

(a) ROM   (b) RAM   (c) DVD   (d) SSD

Show answer

Answer: (b) RAM. RAM normally loses its contents when power is removed.

1 mark

Q3. Which of the following is system software?

(a) Presentation slide deck   (b) Operating system   (c) School report   (d) Photo album

Show answer

Answer: (b) Operating system. It manages system resources and provides services to applications.

2 marks

Q4. Differentiate between data and information with an example.

Show model answer

Data consists of raw facts, such as marks 70, 80 and 90. Information is data processed into a meaningful form; for example, the average of those marks is 80.

2 marks

Q5. Write two differences between RAM and ROM.

Show model answer

RAM is volatile and is used as working memory for currently running programs and data. ROM-type non-volatile memory retains its contents without power and is commonly used to store firmware or startup instructions. Their normal read/write behaviour also differs.

2 marks

Q6. Convert 6 KB into bytes using 1 KB = 1,024 bytes.

Show solution

6 × 1,024 = 6,144 bytes.

2 marks

Q7. What is the difference between a compiler and an interpreter?

Show model answer

A compiler translates source code into another form, commonly object code or an executable, before program execution. An interpreter/runtime executes source instructions through its execution environment. The precise implementation depends on the language and toolchain.

3 marks

Q8. Explain any three functions of an operating system.

Show model answer

Any three: (1) Memory management allocates and tracks memory. (2) File management organises files and controls access. (3) Device management coordinates peripherals. Other valid points include process management, security, user interface and error handling.

3 marks

Q9. Differentiate between general-purpose and specific-purpose application software with examples.

Show model answer

General-purpose software supports common tasks for many users, such as word processing or spreadsheets. Specific-purpose software is designed for a particular task or workflow, such as school fee management, payroll or railway reservation.

3 marks

Q10. Write the four traditional generations of electronic computers and their main technology.

Show model answer

First: vacuum tubes; second: transistors; third: integrated circuits; fourth: microprocessors. Each generation generally improved size, reliability, performance and efficiency.

3 marks

Q11. Give three differences between open-source software and freeware.

Show model answer

Open-source software grants source-code access and licence-defined rights to study, modify and redistribute. Freeware describes software available without a purchase price; its source code may remain closed. Open-source software may be sold commercially, while freeware is not necessarily modifiable or redistributable.

4 marks

Q12. Explain the memory hierarchy and why cache is useful.

Show model answer

A simplified hierarchy is registers, cache, RAM and secondary storage. Higher levels are generally faster, smaller and more expensive per byte; lower levels offer greater capacity at lower cost per byte. Cache keeps likely-to-be-needed instructions and data near the CPU, reducing average access time.

4 marks

Q13. Classify the following: printer driver, spreadsheet, Linux, school payroll application, compiler.

Show model answer
  • Printer driver — system software / device driver.
  • Spreadsheet — general-purpose application software.
  • Linux — operating-system family / system software.
  • School payroll application — specific-purpose application software.
  • Compiler — programming tool / language translator.
5 marks

Q14. Draw or explain the functional units of a computer system.

Show model answer

Draw an input unit sending data to the system, a CPU containing ALU and CU, main memory connected to the CPU, secondary storage for long-term retention, and an output unit. Explain that input data and instructions are processed by the CPU, using memory as needed, and results are delivered to output or stored.

5 marks

Q15. A student permanently deletes a project file. Explain why recovery may or may not be possible and give two preventive measures.

Show model answer

Deletion may only mark the file's storage space as available, so recovery tools may work if the data has not been overwritten. Recovery is not guaranteed, especially on SSDs or if secure deletion has been used. Prevent loss through regular separate backups and by checking the Recycle Bin/Trash before permanent deletion. Cloud version history or a second offline copy can provide additional protection.

11. Quick Revision Sheet

  • Computer system: hardware + software + data + users/procedures.
  • Input: enters data; output: presents results.
  • CPU: ALU performs arithmetic/logic; CU coordinates; registers hold very small, fast working values.
  • Memory hierarchy: registers → cache → RAM → secondary storage (simplified order).
  • RAM: volatile working memory; ROM-type memory: non-volatile firmware storage.
  • Storage examples: HDD (magnetic), SSD/flash drive (flash), CD/DVD (optical), tape (magnetic).
  • School memory conversions: 1 byte = 8 bits; often 1 KB = 1,024 bytes in school calculations.
  • Software types: system software, application software and programming tools.
  • OS functions: process, memory, file, device, security and user-interface management.
  • Four traditional generations: vacuum tubes, transistors, integrated circuits, microprocessors.
  • Open source ≠ freeware: source-code and licence rights differ from purchase price.
  • Data safety: keep separate backups; recovery after deletion is not guaranteed.
