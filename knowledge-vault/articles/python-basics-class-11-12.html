2. Python fundamentals

2.1 A first program, comments and indentation

PYTHON
print("Hello, Python!")
# This is a comment
marks = 87
print("Marks =", marks)

print() displays output. A comment begins with # and is ignored by the interpreter. Indentation (spaces at the beginning of a line) defines a block in statements such as if, for, while and def. Use consistent indentation—normally four spaces.

2.2 Tokens, identifiers and keywords

  • Keywords: reserved words such as if, else, for, while, def, return, True and None.
  • Identifiers: names for variables and functions. They may contain letters, digits and underscores, but cannot begin with a digit. Python is case-sensitive.
  • Literals: fixed values such as 25, 3.5, "CBSE" and True.
  • Operators: symbols/words that perform operations, such as +, // and in.
  • Punctuators: symbols such as parentheses, commas, colons and brackets.
Quick check: total_marks is a valid identifier; 2marks is not. score and Score are different names.

2.4 Input and type conversion

input() returns text (a string), even if the user types digits. Convert the value when arithmetic is required.

PYTHON
name = input("Enter name: ")
age = int(input("Enter age: "))
percentage = float(input("Enter percentage: "))
print(name, age, percentage)

Examples of explicit conversion: int("25") gives 25; float("4.5") gives 4.5; str(18) gives "18". Converting "4.5" directly to int raises a ValueError.

3.1 Division: a frequent output question

PYTHON
print(17 / 5)
print(17 // 5)
print(17 % 5)
print(2 ** 3 ** 2)
Output
3.4
3
2
512

/ performs true division; // gives floor division; % gives the remainder. Exponentiation associates from right to left, so 2 ** 3 ** 2 means 2 ** (3 ** 2).

3.2 Trace the expression carefully

PYTHON
a = 7 + 3 * 2 ** 2
print(a)
Output
19

Exponentiation is evaluated first: 2 ** 2 = 4; then multiplication: 3 * 4 = 12; then addition: 7 + 12 = 19. Parentheses can make the intended order clearer.

Common trap: == compares values; = assigns a value. Use == inside a condition when testing equality.

4. Conditional statements and loops

4.1 if, if–else and if–elif–else

PYTHON
marks = 76
if marks >= 90:
    grade = "A1"
elif marks >= 75:
    grade = "A2"
elif marks >= 60:
    grade = "B"
else:
    grade = "C"
print(grade)
Output
A2

Conditions are checked from top to bottom. The first true branch runs; later branches are skipped. A colon and an indented block are required.

4.2 for loop and range()

PYTHON
for i in range(2, 8, 2):
    print(i, end=" ")
Output
2 4 6

range(start, stop, step) includes the start (when reached) but excludes the stop. Therefore, range(2, 8, 2) produces 2, 4 and 6.

4.3 while loop, break and continue

PYTHON
n = 1
while n <= 5:
    if n == 3:
        n += 1
        continue
    print(n, end=" ")
    n += 1
Output
1 2 4 5

continue skips the remaining statements in the current iteration. break exits the loop. In a while loop, update the control variable so that the loop can finish.

4.4 Classic programming questions

Find the factorial of a number

PYTHON
n = int(input("Enter a non-negative integer: "))
fact = 1
for i in range(1, n + 1):
    fact *= i
print("Factorial =", fact)

For n = 5, the result is 120. The initial value must be 1 because multiplying by 0 would make the result 0.

Check whether a number is prime

PYTHON
n = int(input("Enter an integer: "))
if n < 2:
    print("Not prime")
else:
    is_prime = True
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            is_prime = False
            break
    print("Prime" if is_prime else "Not prime")

A prime number is greater than 1 and has no positive divisors other than 1 and itself.

Sum the digits of a positive integer

PYTHON
n = int(input("Enter a positive integer: "))
total = 0
while n > 0:
    total += n % 10
    n //= 10
print(total)

For input 482, output is 14. n % 10 extracts the last digit and n // 10 removes it.

5. Strings: indexing, slicing and methods

A string is an immutable sequence of characters. Indexing starts at 0 from the left and at −1 from the right. A slice follows text[start:stop:step]; the stop index is excluded.

PYTHON
s = "COMPUTER"
print(s[0], s[-1])
print(s[1:5])
print(s[::-1])
print("put" in s.lower())
Output
C R
OMPU
RETUPMOC
True

The final line converts the string to lowercase before checking membership.

5.2 Exam-style output: partition()

PYTHON
print("Amrit Mahotsav @ 75".partition(" "))
Output
('Amrit', ' ', 'Mahotsav @ 75')

partition() splits at the first occurrence of the separator and returns a tuple containing the part before it, the separator itself and the part after it. If the separator is absent, the original string is the first item and the other two items are empty strings.

Remember: strings are immutable. A statement such as s[0] = "X" causes a TypeError. Methods such as replace() return a new string; assign it if you want to keep the result.

6.3 Linear search and frequency count

PYTHON
numbers = [4, 7, 2, 7, 9]
target = 7
if target in numbers:
    print("Found at index", numbers.index(target))
else:
    print("Not found")

print("Frequency =", numbers.count(target))
Output
Found at index 1
Frequency = 2

For a question that asks you to write linear search yourself, use a loop and compare each element with the target rather than relying on index().

PYTHON — LINEAR SEARCH
numbers = [4, 7, 2, 7, 9]
target = int(input("Search for: "))
position = -1
for i in range(len(numbers)):
    if numbers[i] == target:
        position = i
        break
if position == -1:
    print("Not found")
else:
    print("Found at index", position)

6.4 A subtle mutability question

PYTHON
a = [10, 20, 30]
b = a
b[0] = 99
print(a)
Output
[99, 20, 30]

b = a does not make a separate list; both names refer to the same list. Use b = a.copy() or b = a[:] for a shallow copy.

7. Tuples

A tuple is an ordered, immutable sequence. It supports indexing, slicing, membership, iteration and methods such as count() and index().

PYTHON
t = (10, 20, 10, 40)
print(t[1])
print(t.count(10))
print(t.index(40))
print(t[1:3])
single = (5,)
print(type(single))
Output
20
2
3
(20, 10)
<class 'tuple'>

The comma creates a single-item tuple: (5,). (5) is simply the integer 5 inside parentheses.

Nested list and tuple: a classic misconception

PYTHON
a = [1, 2, (3, 4)]
a[2][1] = 5

This raises a TypeError. The outer list is mutable, but the item at index 2 is a tuple, and tuple elements cannot be reassigned. A list containing a tuple does not make the tuple itself mutable.

8. Dictionaries

A dictionary stores key–value pairs. Keys must be hashable and unique; assigning a value to an existing key updates that value. Dictionaries are mutable.

marks["Aarav"] = 90
print(marks["Diya"])
print(marks.get("Riya", "Not found"))
print(list(marks.keys()))
print(list(marks.values()))
print(list(marks.items()))

94
Not found
['Aarav', 'Diya', 'Kabir']
[90, 94, 81]
[('Aarav', 90), ('Diya', 94), ('Kabir', 81)]

8.2 Count each character using a dictionary

This is a useful long-answer pattern because it combines a loop, a condition and dictionary updates.

PYTHON
text = "banana"
freq = {}
for ch in text:
    if ch in freq:
        freq[ch] += 1
    else:
        freq[ch] = 1
print(freq)
Output
{'b': 1, 'a': 3, 'n': 2}

Shorter equivalent: freq[ch] = freq.get(ch, 0) + 1 inside the loop. If a question asks for a case-insensitive count, process text.lower() first.

8.3 Traverse a dictionary

PYTHON
salary = {"Aman": 25000, "Riya": 30000}
for name, amount in salary.items():
    print(name, amount)

Use for key in d to iterate over keys or for key, value in d.items() to access both components.

9. Functions: parameters, return values and scope

A function is a named, reusable block of code. Define it with def. Parameters receive inputs; return sends a result back to the caller. print() displays a value but does not return it as the function's result.

PYTHON
def area_rectangle(length, breadth):
    return length * breadth

answer = area_rectangle(8, 5)
print(answer)
Output
40

9.1 print() versus return

PYTHON
def first():
    print(5)

def second():
    return 5

x = first()
y = second()
print(x, y)
Output
5
None 5

The first function displays 5 and then implicitly returns None. The second returns 5 to the caller.

9.2 Default and positional arguments

greet("Asha")

Output

9.3 Local and global variables

PYTHON
x = 10

def show():
    x = 4
    print(x)

show()

Output

The assignment inside show() creates a local variable. It does not change the global x. Avoid using global unless the question specifically requires it.

9.4 A function to return the largest of three numbers

PYTHON
def largest(a, b, c):
    if a >= b and a >= c:
        return a
    elif b >= a and b >= c:
        return b
    else:
        return c

print(largest(12, 27, 19))
Output

9.5 Recursion: understand the base case

PYTHON
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(4))
Output
24

Each recursive call reduces the problem. The base case stops the calls. Whether recursion is part of your examinable syllabus depends on the prescribed course/session; learn it if your teacher or syllabus includes it.

10.2 Count words in a text file

PYTHON — EXAM PATTERN
def count_words():
    with open("Notes.txt", "r", encoding="utf-8") as f:
        text = f.read()
    words = text.split()
    print("Word count =", len(words))

count_words()

split() without an argument separates on runs of whitespace, so it handles multiple spaces and line breaks better than splitting on one literal space.

10.3 Count lines that contain a particular word

PYTHON — EXAM PATTERN
def count_python_lines():
    count = 0
    with open("Prog.txt", "r", encoding="utf-8") as f:
        for line in f:
            if "python" in line.lower():
                count += 1
    print("Matching lines =", count)

This counts matching lines, not every occurrence of the word. To count occurrences, split into words or use a suitable counting method and state how punctuation is handled.

10.4 Count vowels, uppercase letters and words

PYTHON
def analyse_file():
    vowels = 0
    uppercase = 0
    words = 0
    with open("Story.txt", "r", encoding="utf-8") as f:
        for line in f:
            words += len(line.split())
            for ch in line:
                if ch.lower() in "aeiou":
                    vowels += 1
                if ch.isupper():
                    uppercase += 1
    print("Vowels:", vowels)
    print("Uppercase:", uppercase)
    print("Words:", words)

Keep the counter initialisation outside the loop. If the task asks for words beginning with a particular letter, inspect each word after split().

10.5 Write to a file

PYTHON
with open("Result.txt", "w", encoding="utf-8") as f:
    f.write("Python is useful.\n")
    f.write("Practise every day.\n")

write() does not add a newline automatically. Include \n where a line break is needed.

Exam caution: opening a file with mode "w" destroys its previous contents. Use it only when overwriting is intended. For practical work, make sure the named input file actually exists in the working directory.

11. CSV and binary file basics (Class XII Computer Science)

11.1 CSV files

CSV (comma-separated values) stores tabular records as text. Python's csv module handles quoted values and commas more reliably than manually splitting every line.

PYTHON — WRITE CSV
import csv

with open("students.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["RollNo", "Name", "Marks"])
    writer.writerow([1, "Aarav", 88])
    writer.writerow([2, "Diya", 94])
PYTHON — READ CSV
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

Rows read by csv.reader are lists of strings. Convert numeric fields with int() or float() before calculations. If the syllabus specifically teaches csv.writer and csv.reader, practise their exact syntax.

11.2 Binary files and pickle

In CBSE Computer Science, binary-file programs commonly use the pickle module to write and retrieve Python records. The key operations are pickle.dump() to write and pickle.load() to read.

PYTHON — WRITE A RECORD
import pickle

record = [101, "Meera", 91]
with open("student.dat", "wb") as f:
    pickle.dump(record, f)
PYTHON — READ RECORDS UNTIL EOF
import pickle

try:
    with open("student.dat", "rb") as f:
        while True:
            record = pickle.load(f)
            print(record)
except EOFError:
    pass

EOFError signals that no more pickled objects remain. In a question requiring search or update, read each record, test the specified field and display or write the matching record as requested. When rewriting a binary file, take care not to lose records that do not match the update condition.

Binary-file search pattern

PYTHON — ILLUSTRATIVE PATTERN
import pickle

def search_student(roll_to_find):
    found = False
    try:
        with open("student.dat", "rb") as f:
            while True:
                rec = pickle.load(f)
                if rec[0] == roll_to_find:
                    print(rec)
                    found = True
    except EOFError:
        pass
    if not found:
        print("Record not found")

This assumes each stored record is a list whose first element is the roll number. Match the record structure given in the examination question.

12. Stack using a Python list

A stack follows LIFO—Last In, First Out. The most recently pushed item is the first one popped. A Python list is commonly used to implement a stack.

  • Push: insert an item at the top, usually with append().
  • Pop: remove and return the top item, usually with pop().
  • Underflow: attempt to pop from an empty stack.
  • Display/peek: inspect items or the top without deleting them, according to the question.
PYTHON — BASIC STACK
stack = []
stack.append("Red")
stack.append("Blue")
stack.append("Green")
print(stack)
print("Popped:", stack.pop())
print(stack)
Output
['Red', 'Blue', 'Green']
Popped: Green
['Red', 'Blue']

12.1 Exam-ready push, pop and display functions

PYTHON
def push_item(stack, item):
    stack.append(item)

def pop_item(stack):
    if len(stack) == 0:
        print("Stack Underflow")
        return None
    return stack.pop()

def display_stack(stack):
    if len(stack) == 0:
        print("Empty Stack")
    else:
        for item in reversed(stack):
            print(item)

Use the exact function names and empty-stack messages stated in the question. If the task says display all items without deleting them, do not call pop() during display.

12.2 Push the last five elements of a list

PYTHON — EXAM-STYLE QUESTION
def push_trail(N, myStack):
    for item in N[-5:]:
        myStack.append(item)

N = [1, 2, 3, 4, 5, 6, 7]
myStack = []
push_trail(N, myStack)
print(myStack)
Output
[3, 4, 5, 6, 7]

N[-5:] selects the last five elements in their original order. This is a concise solution when the question guarantees that the list contains at least five elements.

Q10. Write a function that accepts a list and returns a new list containing only even numbers.

def even_numbers(values):
    result = []
    for value in values:
        if value % 2 == 0:
            result.append(value)
    return result

print(even_numbers([3, 8, 11, 14, 20]))

Output: [8, 14, 20].

Q11. Write a function to count how many times the word “python” occurs in a text file, ignoring case.

Show solution
MODEL ANSWER
def count_python():
    count = 0
    with open("Prog.txt", "r", encoding="utf-8") as f:
        words = f.read().lower().split()
    for word in words:
        word = word.strip(".,!?;:()[]{}\"'")
        if word == "python":
            count += 1
    print("Python occurs", count, "times.")

This solution ignores case and removes common punctuation around a word. If your textbook or question defines a simpler counting rule, follow that rule exactly.

def display_above_90():
